Welcome to **Notes + Learn** — a simple markdown-based notes and learning app.

## Why this setup?

- Notes live as files under `content/notes/`
- Frontmatter carries title, date, tags, and an optional topic
- No database — Git is the source of truth

## Daily habit

1. Create a file: `content/notes/YYYY-MM-DD-slug.md`
2. Fill in frontmatter
3. Write freely in Markdown
4. Commit and push (or deploy)

## Tips

- Use **topics** for learning tracks you want to review later
- Use **tags** for cross-cutting themes
- Keep daily notes short; link out when something grows into a longer piece

Happy writing.
